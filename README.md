## 🧩 Featured Project

### 💻 LapZone — Laptop E-commerce Web Application

LapZone is a full-stack e-commerce project designed for a local computer business.  
The goal is to help the business improve its digital presence, display laptop products online, manage inventory, and allow customers to interact with the store through a modern web platform.

#### Main features:

- Product catalog for laptops
- User registration and login
- Role-based access for customers and administrators
- Admin panel for product management
- Shopping cart
- Order management
- Payment flow concept using Stripe and alternative payment methods
- PostgreSQL database integration
- REST API communication between frontend and backend

#### Technologies used:

- **Frontend:** React, JavaScript, CSS
- **Backend:** Java, Spring Boot, Spring Security
- **Database:** PostgreSQL
- **Tools:** Git, GitHub, IntelliJ IDEA, pgAdmin, Postman
- **Architecture:** Modular monolithic backend with REST API
